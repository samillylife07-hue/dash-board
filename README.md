# 📊 Dashboard de Atendimento

Este é um painel (dashboard) criado para otimizar e organizar rotinas de atendimento, substituindo planilhas manuais por uma interface ágil e visual.

## 🚀 Funcionalidades
- Organização de chamados/atendimentos.
- Interface limpa e amigável.
- Acompanhamento em tempo real de produtividade.
- Identificação de gargalos e destaques.
- Filtros e barra de pesquisa

 ## 📊 Beneficios 
- Responsivividade
- Modo noturno
- Intuitivo
- Atualizações em tempo real mediante a alimentação da planilha
